# Muse Wonder

[[meta|Meta]]가 2026-10-12에 발표한 모델(해설 기준). [[muse|Muse]]의 개인 에이전트 작업에 **코딩 프로젝트 지원**을 더한다. **이 페이지의 모든 내용은 Tech Bridge 해설이 Meta 공식 자료를 요약한 것이다**([[tech-bridge-alexandr-wang-muse-launch]] 08:05~08:28). [[alexandr-wang|Wang]]의 발화가 아니고, 이 위키는 Meta 자료를 열어 보지 않았다.

> *"It is a model that handles personal agent tasks while also assisting with coding projects. Developers can now use Wonder in the Meta model API and Muse Code, and Wonder Full is provided to Muse Code subscribers. Meta has announced that Wonder is scheduled to be included in the Muse app as well in the future."* (해설, 08:09~08:28)

| 항목 | 값 (해설) |
|---|---|
| 발표 | *"The day after this interview was released, on October 12"* |
| 용도 | 개인 에이전트 작업 + 코딩 프로젝트 지원 |
| 제공처 | **Meta model API**, **Muse Code**(이 위키에 처음 나오는 제품명, 설명 없음) |
| 변형 | **Wonder Full**: Muse Code 구독자에게 제공(Wonder와의 차이는 미설명) |
| Muse 앱 | *"scheduled to be included (…) in the future"* |

⚠️ 벤치마크·가격·크기가 없다. **[[muse-spark|Muse Spark]](1.3)와의 관계(후속인지, 병행 계열인지)도 소스에 없다.**

> ⚠️ **긴장.** Muse가 *"not coding"*(원음 ②)으로 자리 잡은 지 약 한 달 만에 같은 이름 아래 코딩 지원 모델과 Muse Code가 나왔다. Zuckerberg의 *"개인 에이전트에서 말하는 것 상당수가 결국 코딩으로 환원된다"*([[muse]])와 같은 방향이다.
