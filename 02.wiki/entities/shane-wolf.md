# Shane Wolf

[[atlassian|Atlassian]]의 manager이며 context engine과 code chat을 맡고 있다. [[andy-wong|Andy Wong]]이 *"We have Shane Wolf uh manager down in Devi space"*(00:15~00:18)로 소개했다(*"Devi"* 는 판독 보류). 47:15~47:23에는 *"He's working a lot on code chat"* 이라며 발언을 넘겼다. [[tech-bridge-atlassian-build-your-own-sdlc]]가 이 위키의 첫 등장이다. ([[thomas-wolf|Thomas Wolf]](Hugging Face)와 다른 사람이다.)

## 위키에서 알려진 사실

- *"I think we have 15,000 repositories across the company"*(47:40~47:44). 그래서 "어디에 구현하나·어떤 서비스가 이걸 쓰나" 같은 질문이 *"really really complicated"* 하다고 말했다.
- context engine의 핵심을 검색 공간을 좁히는 일로 설명했다. *"narrowing down the retrieval and the search space to scope it to like where this answer is most likely uh lives within the code"*(47:56~48:07) → [[context-engine]]
- 문서는 낡았지만 결정의 이유는 가치가 있다고 봤다. *"historical information about why decisions were made are something that's often left out of um agent generated code, but it's really important"*(49:01~49:09)
- (⚠️ 추정 — 49:26~51:15도 같은 화자로 보임) Rovo Chat code context가 얼리 액세스라고 했고(50:05~50:11), *"the context engine itself is more agentic search"*(50:56~51:00), Teamwork Graph CLI로 노출한다(50:50~51:15)고 설명했다.
- 장애 중 Q&A 응답자는 그를 *"Shane who's currently working on Wi-Fi. So connectivity basically is his through line"*(17:49~17:53)이라고 불렀다. 행사장 Wi-Fi를 고치고 있었다는 농담과 그의 팀 일(연결성)을 겹친 말이다.

## ⚠️ 유보

- 직함은 *"manager"* 만 발화된다. 링크는 설명란에서 가져왔고 열어 보지 않았다.
