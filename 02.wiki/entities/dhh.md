# DHH

David Heinemeier Hansson. Ruby on Rails 창시자, 37signals CTO. 본 위키 첫 등장은 Lex Fridman 클립 Tech Bridge 재배포([[tech-bridge-dhh-agent-productivity]]).

## 위키에서 알려진 사실

- [[omarchy|Omarchy]] 3개월 작업에서: **10x·100x는 에이전트와 직접 대화할 때만**. 사람 승인 계층으로 중개하면 이득이 죽는다.
- 대기업 병목은 구현이 아니라 **아이디어·비전·taste**. 무한 프로그래머를 가진 조직도 매력적인 소프트웨어를 자동으로 만들지 못한다.
- 옛 방식에 맞춘 슈퍼탱커는 innovator's dilemma — 경로는 조직 안 가속보다 **밖에서 자기 5%를 다시 쓰는 것**.
- 원래 Ruby. 에이전트로 C++/Qt 폴리글롯. Omarchy Write: Typora의 5%를 ~20분 초안·이틀 만에 교체.

ASR "Amachi"/"Amacha"는 Omarchy로 통일.
