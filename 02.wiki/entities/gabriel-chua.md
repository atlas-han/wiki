# Gabriel Chua

[[openai|OpenAI]] **developer experience 팀** 소속, 싱가포르에서 온 발표자. [[charlie-guo|Charlie Guo]]와 [[ai-engineer|AI Engineer World's Fair]] 2026 워크숍 *"Cooking with Codex"* 를 진행하며 **데모 대부분**(번역 앱, 컴퓨터 사용, 밤새 돌린 장기 과제, 자동화, Retrodex)을 맡았다 → [[tech-bridge-cooking-with-codex]].

> ⚠️ **신원 근거.** 발화엔 *"my name is Gabriel, also on the developer experience team, flying in from Singapore"*(00:22~00:27)뿐 — **성 Chua는 제목·설명란(x.com/gabrielchua · github.com/gabrielchua · gabrielchua.me)에만** 있다(링크 미확인). ko 52:46의 "추아"는 `en`의 *"Gabriel Chua"* 를 물려받은 것으로, en-orig 52:42~52:47엔 *"users all called Gabriel"* 뿐이다. 동료는 *"Gabe"* 라 부른다(09:01, 43:17).

## 위키에서 알려진 것 (자기 서술, 2026-06-29)

- *"I'm the data scientist by training"*(13:11~13:14), WebRTC·websockets엔 익숙하지 않다(13:14~13:20), *"I've never built a Mac OS app"*(06:46~06:48) — 그런데 플러그인의 모범 사례로 macOS 실시간 번역 앱을 만들었다(화자 서술 *"4 minutes and two seconds"* 12:51~12:57, ⚠️ 출력은 자막에 없음).
- *"I used to work in a large organization before open AAI[=OpenAI] and not everything had an API"*(21:27~21:33) — 컴퓨터 사용 데모의 동기.
- 대학원 시절 논문(Julia·R)을 Rust 백엔드 Python 패키지로 재구현하는 7시간 과제(31:29~31:51).
- **장기 과제 운영법** — goals.md + progress dashboard.html, 목표 감사 스레드, 원격 스레드가 로컬 스레드를 띄워 Chrome QA, Slack 보고, side thread로 막힘 해소(32:05~40:33) → [[verifiable-goals]] · [[cloud-agent-delegation]] · [[agent-visual-qa]]
- *"does prompt engineering matter? In so far as the instructions are clear, it still matters (…) I don't think we're in that state anymore"*(29:59~30:17).
- 자동화: 매주 금요일 스킬 정리, 실제 답장과 초안을 대조하는 두 번째 자동화(56:06~56:43) → [[skill-self-improvement]]. 훅은 *"guardrail"*(49:52~50:01) → [[hook-enforced-workflow]]
- App Server 위 자체 UI **Retrodex**(59:39~1:00:46).

- 같은 팀의 후속 소스: [[dominik-kundel|Dominik Kundel]]의 [[codex-app-server|App Server]] 발표([[tech-bridge-codex-app-server]], 2026-10-14) — 워크숍 §6이 소개만 한 App Server를 17분 전체로 푼다.
