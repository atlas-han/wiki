# Palantir

데이터 분석 · 통합 플랫폼 회사. 정보기관 · 국방 고객으로 시작했다. CEO는 [[alex-karp|Alex Karp]].

> ⚠️ **위키의 근거는 한국어 해설 하나다**([[tech-bridge-alex-karp-wealth-tax-surveillance]]). S-1 · 주주 서한 · X 게시물은 해설이 인용한 것이고 위키는 열지 않았다.

## 알려진 것 (해설)

- 창업 2003년, 첫 플랫폼 Gotham 출시 2008년, 매출 집계도 2008년부터(상장 서류 S-1, 해설의 대조). Karp의 *3년 무매출* 서술과는 어긋난다.
- 기원: PayPal의 사기 탐지 기법을 정보기관으로 — Peter Thiel의 제안. In-Q-Tel(CIA 투자 조직)이 초기 투자.
- 자기 서술: *테러도 막고 시민의 자유도 지키는 제품*. 유럽에서 영장이 있을 때만 데이터를 보관하고 끝나면 지우는 것을 *기술로 지키게* 한다(Karp). *수백 건의 테러 저지* 는 공식 수치가 아니다(해설).
- ⭐ **AI 주권을 사업 언어로** — 2026년 7월 X 게시물 *"데이터 보안은 당신의 보물이다. 넘긴다면 위험은 당신 몫이다."*(1,300만 회 이상 조회), 8월 주주 서한 *"우리 고객들은 언어 모델 연구소의 속국이 되기를 거부했다."* → [[ai-sovereignty]]
- 감시 논란을 달고 다니는 회사라는 점을 해설이 반복해 짚는다.
