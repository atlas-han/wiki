# Amazon

이 위키에는 리테일 본업보다 **사내 코딩 에이전트 파일럿**의 무대로 먼저 등장한다. 출처 [[tech-bridge-frontier-engineering]] ([[clare-liguori|Clare Liguori]] / AWS).

## 위키에서 알려진 사실

세 층위 실험 (영상 수치, 내부 측정):

1. **Bedrock Mantle** — 새 inference data plane. 추정 30명×18개월 → 6명×76일 ([[kiro|Kiro]]). 커밋 기준 최대 20x. distinguished engineer 2명 포함.
2. **Prime Video** — 10일 스프린트, 6명, 온콜·회의를 걷어낸 방. 전달 추정 90주→24주. 시니어가 사전 3주 태스크를 만들어 둠.
3. **Amazon Stores** (amazon.com · 리테일 웹 · 오프라인) — 평범한 50팀, 기존 코드베이스, 배포 속도. 절반 <3x, 절반 중앙값 4.5x. 90%가 같은 도구.

2026 과제: 파일럿 50팀에서 **다음 2,000팀**으로 스케일. 새 병목은 손코딩이 아니라 **의사결정·런칭 리뷰**.

AWS / Bedrock / Prime Video / Stores는 이 페이지에 묶고 개별 엔티티는 만들지 않음.
