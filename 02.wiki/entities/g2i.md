# G2i

[[gabriel-martinez|Gabriel Martinez]]가 engineering manager로 일하는 조직이다(*"engineering manager and resident slop warden at G2i"* 00:04~00:08). **무엇을 하는 회사인지는 발화되지 않는다.** 링크는 설명란에서 가져왔고 열어 보지 않았다. 이 위키 첫 등장이다.

## ORC

- 이름 표기 ORC는 챕터(*"우리가 ORC를 만든 이유"*)와 설명란(*"ORC by G2i: https://orc.ai"*)에서만 나온다. en-orig는 *"Ork"* 다.
- 동기: *"We built Ork because we kept seeing the same failure pattern. AI could generate code, but the surrounding discipline was still missing. The planning, the review, the adversarial checks, the context management."*(15:45~15:57)
- 자기 규정: *"Ork is taking those lessons and baking them into the workflow. It is not a magic box that makes correctness disappear as a human responsibility. It is a system for preserving that responsibility while letting agents do more of the lift."*(16:11~16:23)
- ⚠️ 기능·인터페이스·adversarial checks의 구현·사용자·효과 수치는 발화되지 않는다. 당사자 발표다.
