# Peter Steinberger

[[openclaw|OpenClaw]]의 제작자. 해설에 따르면 2026년 2월 [[openai|OpenAI]]에 합류했고 [[sam-altman|Sam Altman]]이 직접 발표했다. 이 위키에는 두 소스에서 이름만 나오다가(아래), 11-09 [[tech-bridge-peter-steinberger-2027-developer]]에서 처음으로 그를 다루는 소스가 들어왔다.

> ⚠️ **본인 음성은 캡션에 없다.** 11-09 소스는 Amigoscode 인터뷰(`KrlaBpyWH_k`)와 본인 블로그(steipete.me)를 한국어 해설자가 옮긴 2차 전달이다. 원음으로 보이는 발췌 여섯 곳은 두 자막 트랙 모두 무캡션이다. 위키는 인터뷰 · 블로그 · Altman 게시물을 열지 않았다. 이름의 라틴 표기는 설명란 · tags 근거다(ko ASR *피터스 타임버거*, 영어 더빙 *Peter Steinberg*). 블로그 도메인 `steipete.me`는 설명란 링크에서 왔다.

## 해설이 전하는 이력 (2026-11-09 · 2차 전달)

- Altman이 *"다음 세대 개인 에이전트를 이끌 사람이라고 그리고 천재라고요."*(00:43~00:48) 소개했다(1600만 회 이상 조회).
- OpenClaw 저장소는 2025년 11월에 생겼고 GitHub 스타가 39만 개를 넘는다(00:56~01:01).
- *"그 전에는 13년 동안 회사를 키웠던 사람이에요."*(01:03~01:06) 회사 이름은 발화되지 않는다.
- *"오픈 클로로 큰 회사를 만들 수 있었지만 자기는 뼈속까지 만드는 사람이라며 오픈 AI를 택했습니다."*(01:06~01:12)
- 오픈소스 프로젝트 약 40개를 관리한다. 정기 세션이 의존성 업데이트와 이슈 · PR 확인을 돌리고, 본인은 *"한층 위로"*(01:17~01:19) 올라가 원하는 기능과 들어온 PR을 고른다.

## 하는 말 — 2027년의 개발자 (2026-11-09)

- *"내 코드의 거의 100%를 에이전트가 쓴다."*(00:24~00:28, 블로그 인용). 그런데 AI가 쓴 메일과 *"프롬프트 한 번으로 만든 거 같은 웹사이트"*(03:36~03:37)는 열지 않는다 → [[ai-slop]]
- 가장 중요한 능력은 [[high-agency|하이 에이전시]]다. 문제와 함께 해결책을, 말 대신 프로토타입을 들고 온다.
- '소프트웨어 엔지니어'라는 말이 좁아졌다. 제품 감각, 곳에 따라 디자인 · 마케팅까지 → [[ai-jobs-impact]]
- RAG · 서브에이전트에 시간 쓰지 말고 *그냥 말을 걸라*(블로그 *Just Talk To It*, 설명란 제목)
- 앞으로 2년, 모델이 일을 더 가져갈수록 사람의 책임은 커진다. 소프트웨어 엔지니어는 *별표를 단* 예다.
- 블로그 추신: *"이글은 100% 손으로 썼다. 오타도 내 목소리도 그대로 둔다."*(05:28~05:31) → [[human-provenance-value]]
