# Lydia Hallie

[[anthropic|Anthropic]] [[claude-code|Claude Code]] 팀 소속(설명란 · 내레이션 근거). AI Engineer Code Summit에서 *"Rethinking Claude Code Best Practices"* 를 발표했고, [[tech-bridge|Tech Bridge]]의 한국어 해설로 위키에 들어왔다.

> ⚠️ **본인 원음은 위키에 없다.** 해설 영상의 발표 발췌는 ko-orig에 캡션이 없어 내용 미상이고, 아래는 모두 해설자의 요약이다. 직함 · 경력은 발화되지 않는다.

## 위키에서 알려진 것

- [[tech-bridge-lydia-hallie-rethinking-claude-code-best-practices]](2026-11-12 업로드) — 예전 모범 사례를 **사람이 하던 다섯 가지 일(조종 · 승인 · 거절 · 확인 · 시작)** 로 정리하고, 각각이 모델 · auto mode · 거절 규칙과 환경 · 훅과 CI · Claude로 옮겨 갔다고 말한다 → [[human-loop-roles-relocation]].
- 거절 규칙의 기준은 질문 하나 — *되돌릴 수 있는가?*(챕터 제목, 발화는 무캡션) → [[action-reversibility]].
- 본인 팀의 운영(해설 전달): 모든 PR을 Claude가 새 컨텍스트에서 먼저 리뷰하고 사람 리뷰 수를 위험도로 정한다(0 · 1 · 2명) · 지휘자 세션은 Fable, 작업 스레드는 Opus 5.5 → [[risk-proportional-human-review]] · [[model-mixing-economics]].
- 제안: *평소보다 훨씬 큰 일 하나를 클라우드에서 돌려 보고, 내가 어디서 아직 끼어드는지 보라.*
