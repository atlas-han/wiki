# Roshan Sadanani

[[cursor|Cursor]] 소속. [[grokbot|GrokBot]] 제품 측 설명을 맡았다 ([[tech-bridge-grokbot-agent-teams]]).

## 위키에서 알려진 사실

- 사내 채택 경로를 **내부 PMF → 외부 출시 신호**로 정식화. 만드는 것을 내부 배포하고 매일 쓰는 다른 부서 피드백을 본다. GrokBot도 같은 경로.
- GrokBot의 특이점으로 **역할 무관 접근성**을 지목 — 시장 진출·운영·엔지니어링·제품 팀 모두가 각자 활용법을 찾음. 이유는 기존 도구와의 연동 + **자체 컴퓨터를 가진 지속형 에이전트**.
- 병목 분석: *"아이디어에서 실제 제품으로 이어지는 과정에는 항상 병목 현상이 존재"* — 아이디어는 남아돌고 **변환**이 병목. [[dhh]]가 병목을 아이디어·taste로 본 것과 대비된다.
- 목표는 여러 에이전트를 직접 관리하든 에이전트에게 다른 에이전트를 관리시키든 **업무 주기를 압축**하는 시스템.
- UI 철학: 힘과 복잡성의 균형. *"어떻게 하면 이 기능을 최대한 간단하게 만들 수 있을까"* → 메시징 인터페이스.
- 모델 방향: [[grok-4-6|Grok 4.6]]은 SpaceX AI 팀과의 **코드 학습을 넘는 범용 훈련** 방향의 연속. **효율성에 엄청난 투자** 중.
