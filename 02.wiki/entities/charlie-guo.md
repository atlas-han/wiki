## 위키에서 알려진 것 (전부 2026-06-29 발화, 당사자 진술)

- **goal을 쓰는 법** — *"be really specific with the criteria (…) you want that criteria to be as verifiable as possible"*(43:32~43:43). goal은 *"kind of like a genie"*, 안 될 땐 *"a monkeykey's paw type situation"*(43:45~43:59) → [[verifiable-goals]]
- **서브에이전트 vs 스레드 간 핸드오프의 기준** — *"when the the delegation of work needs to be visible to you, the user versus when it just needs to be visible to the model"*(45:49~45:59) → [[subagent-vs-thread-handoff]]. 본인 사례: 게임 제작에서 **creative director 스레드**의 sign-off를 받게 한 AGENTS.md(46:45~47:34).
- **hooks** — config.toml, 결정론적 체크포인트, 보안 용도; *"give the model as many boundaries as (…) you can and let it fill in the lines"*(49:02~49:09) → [[hook-enforced-workflow]]
- **브라우저·컴퓨터 제어 선택표** — in-app browser(로컬 웹앱 깊은 테스트) / computer use(프로그래매틱 인터페이스 없는 앱) / Chrome extension(로그인·권한 넘기기)(26:05~28:15) → [[agent-native-interface]]
- **개인 자동화** — Slack·이메일·Linear 알림에 *"drowning"*, 이를 훑어 **로컬 [[obsidian|Obsidian]] vault**의 일일·작업 흐름 노트를 갱신하는 heartbeat 자동화(57:17~57:51) → [[scheduled-agent-automations]]
- 받아쓰기·appshot을 *"heavily underused"* 라 부른다(17:35~18:28). 어려운 대화의 끝은 *"make this a skill or even better make this a plugin"*(12:41~12:48, 화자 추정).
- **마무리 사다리** — *"have you asked Codex?"* → *"loop maxing"* → 무엇이 막았나 → 하나에서 여럿으로 → *"why does this process need a human at all"* → *"build the machine that builds the machine"*, *"software factory"*(1:01:54~1:04:21) → [[loop-is-the-product]] · [[software-factory]] · [[human-plumbing]]
