# Ignacio Martinez

[[oracle|Oracle]]의 AI 개발자 애드버킷(설명란: *"오라클의 AI 데브렐"*). 이 위키에는 **에이전트 메모리·하네스 엔지니어링 워크숍**([[tech-bridge-oracle-agent-memory-harness]], 2026-09-23 업로드)으로 처음 들어왔다.

> ⚠️ **이름·직함은 설명란에만 있다.** 자막(en-orig·en 변종·ko)에 *Ignacio / Nacho / Martinez* 는 한 번도 나오지 않는다. 2026-09-02 원칙대로 설명란을 따른다. X 핸들 `nacho_martinez` 도 설명란 링크다.

## 자막에서 확인되는 것

- *"오라클에서 7년, 그중 약 4년 개발자 애드버킷"*(01:27~01:35, en-orig *"I've been working for Oracle for seven years. I've been a developer advocate for about four of them"*). GitHub 활동이 활발하다고 스스로 말한다.
- *"내 경력의 정점"* — **[[andrew-ng|Andrew Ng]]과 에이전트 메모리 강좌를 냈다**(01:45~01:50). [[toolbox-pattern|툴박스 패턴]]을 그 강좌에서 소개했다(48:46~48:51). 동료 *"Casio"*(⚠️ 이름 미확정)와 **지속 학습 강좌를 녹화할 예정**, *"몇 주 뒤"*(12:26~12:41). ⚠️ **강좌명·플랫폼을 자막이 말하지 않는다.**
- 스스로를 *"한 번에 8, 16, 32개의 에이전트로 일하는 degenerate"* 라 부른다(14:44~14:51).
- 데모에 쓰는 모델은 *"Grog/Groq 4.1 fast reasoning"*(52:41~52:44, ⚠️ xAI Grok 4.1 Fast로 읽힘, 미확정), 도구 호출 상한은 **8~12회**(52:49~52:53, 개인 경험).
- 워크숍 Codespaces 비용을 *"제 사비로"* 낸다고 한다(43:22~43:25).
