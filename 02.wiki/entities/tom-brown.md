## 발언 (자막 근거, 18:18~19:25)

- Opus 5.5는 *"a model that I think just continues the normal progress that we've had of getting kind of more IQ points for each of these super intelligences, uh, with each model release"* — **"정상적 진보"라는 스스로 낮춘 평가**.
- 사용자에게 보이는 것: *"it can do a task that takes a longer time than they'd be able to delegate to to a previous model"* → [[goal-level-delegation]]
- 덜 보이는 것: *"there's going to be a huge amount of software being written by these models. And so all of the products that people use are going to be getting higher quality, cheaper over time."*
- ⚠️ 진행자의 *"where are we going to be in a year?"*(18:15~18:18)에는 **답하지 않았다.** 이어진 가치관·공동 선언 질문에도 발언이 없다.
