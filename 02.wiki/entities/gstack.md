# gstack

[[garry-tan|Garry Tan]]이 만들었다고 말하는 오픈소스 프로젝트. Claude Code에 넣어 쓰는 자기 작업 구성이다. 저장소를 열지 않아 구성 요소는 알 수 없다.

## 제작자의 설명

- 목적: YC 창업자들이 *"get 400 times the amount of output that they had before"*(06:07~06:10) 내도록 가르치는 것.
- 사용법: *"just drop into Claude code and get exactly the stack that I used to get that."*(06:14~06:19)
- 재교육 수단으로도 말한다: *"I think something like G stack or like lots of other efforts out there could solve that"*(06:50~06:58)

> ⚠️ *400배*는 측정 방법 · 기준선이 없는 제작자 진술이다. 그것이 재교육 문제를 푼다는 말도 근거 없는 희망으로 말한다.

## 위키의 다른 언급
