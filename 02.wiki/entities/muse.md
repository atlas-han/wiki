# Muse

[[meta|Meta]]의 **개인 에이전트(personal agent)**. 본 위키 첫 등장은 [[tech-bridge-zuckerberg-muse-personal-agent]].

> **목표는 세상 모든 사람에게, 자기 목표를 이해하고 24시간 자기를 대신해 일해 줄 아주 유능한 개인 에이전트를 주는 것**입니다. ([[mark-zuckerberg]], 04:20~04:34)

> ⚠️ **이 페이지의 모든 내용은 [[mark-zuckerberg|CEO]] 한 사람의 진술이다.** 제3자 리뷰도 벤치마크도 없고, **사용자 수·가격·성능 수치가 하나도 없다.**

## 형태

| 요소 | 내용 |
|---|---|
| **핵심** | **가상 머신을 뒤에 붙인 장수명(long-lived) 에이전트** |
| **입력** | 프롬프트가 아니라 **프로젝트 또는 목표** |
| **동작** | *"그냥 일한다 — **24시간**, 목표 달성을 도울 때까지 멈추지 않는다"* |
| **밤 공부** | *"성찰을 **메모리로 굳힌다(consolidate)**"* (진행자 표현: *"밤에 공부한다"*) |
| **능동성** | **새 프로젝트를 스스로 제안한다** |
| **UI** | 메인 탭은 채팅, 별도 탭에 **확장 아이디어** |
| **커넥터** | 이메일·메시징·건강 정보·Meta 광고 시스템 — **전부 선택** |
| **모델 주기** | *"대략 매달 의미 있는 업데이트"* |

→ [[goal-level-delegation]] · [[agent-memory]]

**화자는 이 형태가 Meta 고유가 아니라고 명시한다** — *"이건 업계에서 더 넓게 일어나고 있습니다 — [[grokbot|GrokBot]]이든 [[town|Town]]이든 Instinct든, 이렇게 하는 제품이 많습니다."* ⚠️ **ko 자막이 이 열거를 통째로 삭제했다.**

## 경제 모델

| 항목 | 값 |
|---|---|
| **무료 한도** | **주당 1억 토큰** + 가상 머신 (*"컴퓨터가 꽤 많이 딸려 오는 셈"*) |
| **구독** | 선택 가능 |
| **수익원** | **거래 수수료** — *"거래가 무엇이든 그 아주 작은 몫만 뗀다"* |
| **부담 주체** | *"결제하는 개인이 아니라 **그들이 거래하는 기업들**"* |
| **결제** | **Stripe** |

> **이게 실제로 돈을 벌어다 주고 아껴 줄 거라고 우리가 뒤에서 보증하는 것이고, 그렇게 해서 스스로 값을 치를 겁니다.**

→ [[transaction-cut-monetization]]

⚠️ **무료 한도 초과 시 단가와 수수료율이 소스에 없다.**

## 차별화 주장 (셋)

1. **모델을 이 용도에 맞게 바닥부터 설계** — *"다른 회사가 선반에서 뭔가 가져와 조금 사후학습해서 바닥부터 설계한 것만큼 잘할 방법은 없다. 그냥 일어나지 않을 일이다."*
2. **소셜 DNA** — *"관계를 강화하고 삶의 부드럽지만 아주 중요한 부분에서 더 얻도록 돕는 쪽에, 다른 어떤 랩보다 더 주의를 기울일 회사."*
3. **프라이버시와 보안** — 아래.

## 보안 아키텍처 (네 겹)

| 층 | 내용 |
|---|---|
| **[[confidential-vm\|기밀 VM]]** | *"Meta조차 그 안의 내용을 볼 수 없다는 약속을 할 수 있고, **그 약속은 기술적으로 검증 가능하다**"*. [[moxie-marlinspike\|Moxie Marlinspike]]가 전담 |
| **[[sentinel-agent\|센티널 에이전트]]** | 들어오고 나가는 트래픽·데이터를 감시. **프롬프트 인젝션 시도**와 **과잉 공유**를 보고 **사람 검토를 트리거할 권한**을 갖는다 |
| **[[least-privilege-connectors\|최소 권한 커넥터]]** | *"이메일에 연결하면 **읽기 전용으로 시작**한다. 보내게 하고 싶으면 따로 요청하면 된다"* |
| **보안 자격증명 저장소** | *"에이전트는 신용카드·비밀번호·일회용 카드 번호를 **알아서는 안 된다.** 로그인해 달라고 요청했을 때 필요한 만큼만"* |

> **로그인·결제·민감 정보 전송은 매번 승인해야 합니다. (…) Muse 에이전트는 그런 판단을 스스로 내릴 수 없습니다. 그건 시스템과 아키텍처에 꽤 깊이 박혀 있습니다.**

⚠️ **한계가 하나도 논의되지 않는다** — 센티널의 탐지율·오탐, **센티널 자신이 인젝션의 대상이 될 가능성**, 기밀 VM의 검증 방법.

## 함대 학습

> **에이전트가 함대(fleet)의 나머지로부터 익명화된 통찰을 배운다.** (진행자 요약, 화자 동의)

> **지금 업계 대부분은 에이전트를 싱글 플레이어 게임처럼 생각합니다.** (…) **이번 릴리스에서는 대부분 나가지 않지만, 시간이 지나면 중요한 부분이 될 겁니다.**

동기가 도입 문제와 연결된다 — *"AI의 큰 문제 하나는 많은 사람이 그걸로 뭘 해야 할지 모른다는 것"*.

→ [[agent-fleet-learning]] · [[agent-org-adoption]]

⚠️ **"익명화"의 정의·집계 방식·옵트아웃이 전부 없다.**

## 필요로 하는 모델 능력

**코딩**(*"개인 에이전트에서 말하는 것 상당수가 결국 코딩으로 환원된다"* — MMA 비주얼 파이프라인도, 베타 사용자가 만든 Jeopardy 게임도)과 **[[discretion-capability|신중함(discretion)]]** — *"무엇이 민감한지를 백만 개 질문을 하지 않고도 알아야 한다."*

## 베타에서 관찰된 사용 (화자 전언)

- 하루 만에 **홈스쿨링 운영**에 씀
- 12시간 만에 **여행 계획 전체**
- 기술에 회의적인 지인: *"정식 출시하면 **내 Muse 에이전트 계속 쓸 수 있어? 리셋할 거야?**"*

⚠️ **베타 규모·기간·선정 방식이 없다.**

## Meta AI와의 관계

*"별개"* 로 본다 — **Muse는 더 대화적이고 장기 목표를 해석해 오래 일하러 가고**, 명확한 답을 원할 때는 Meta AI. *"시간이 지나면 수렴할 수도 있지만 확신은 없습니다."*
