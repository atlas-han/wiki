# Demis Hassabis

[[google-deepmind|Google DeepMind]] 창업자(1인칭 *"when I set up deep mind"*). 이 위키 첫 소스는 [[tech-bridge-hassabis-fry-creativity-future]] — RSA 저녁 행사에서 [[hannah-fry|Hannah Fry]]와 나눈 대담 + 청중 질문 3건(39:41, 발췌). DeepMind의 **첫 창업자 목소리**다.

> ⚠️ **신원 근거.** 이름은 제목·설명란 기준. en-orig는 *"Dennis"*(23:18, 34:31)·*"Deis"*(34:39), `en`·ko는 34:32·34:38에서 *"Demis"*·"데미스". **CEO 등 직함은 발화되지 않는다.** 1인칭 경력 단서: Elixir Studios(*"my own company"* 04:37~04:41) · Cambridge 컴퓨터과학 학부(07:35~07:36) · 신경과학 박사(기억·상상력, 2000년대 초) · MIT 포스닥 중 DeepMind 설립(31:51~31:56) · 북런던 출생(30:53~30:55) · 16세에 게임 디자이너 경력(진행자 발화 03:50~03:53).

## 위키에서 알려진 것

- **게임 디자인 = 과학 연구**: *"if you knew the answer already, then it wouldn't be research. If you knew could guarantee it was going to be fun then it wouldn't be creative"*(05:49~05:58) — 둘 다 *"taste and intuition and kind of faith"*(06:03~06:09). 다학제 팀이 AlphaFold·AlphaGo 성공의 이유(06:55~07:07). → [[taste-vs-judgment]]
- 두 축 = **지능과 시뮬레이션**, 궁극 질문 = 실재의 본성(11:22~12:25). Elixir Studios를 AI 연구 자금의 *"Trojan horse"* 로(04:35~04:44).
- **AI 창작 도구**: 최고 예술가와 공동 설계(Darren Aronofsky, Eve Online 개발사), AI slop = *"creatively mundane"* + *"hook an audience for a few seconds"*(13:48~14:04). → [[ai-slop]]
- **두 시기**: 향후 ~10년 창의성의 개화(*"10x"*), 그 뒤 자율 도구 → *"the human connection (…) craft and soul will be more important than ever"*(16:50~16:58, 추측). → [[human-provenance-value]]
- *"the future is really not written"*(18:56~18:58) / AI 혁명은 *"can't be stopped"*(36:40~36:43) — 일어나는 건 확정, 모양은 미정.
- 최선의 미래 = 질병·소재·에너지·핵융합 → *"a world of abundance"*(21:16~21:19). → [[intelligence-abundance]]
- *"it became commercial earlier than I thought I would have done more scientific and alphafold type things first um and then gone to the more commercial chat bots"*(37:24~37:33).
- 데이터센터도 *"make them beautiful"*(30:14~30:18) → [[data-center-local-backlash]]. 교육: *"invert the classroom"*(38:12) → [[ai-flipped-classroom]]
- Turing 편 — 인간이 하는 일 대부분은 결국 계산 가능(25:03~25:15), Penrose의 양자 의식엔 동의하지 않음.

⚠️ 미래 서술(10년 10x, 질병 *"maybe all of them eventually"*, 핵융합)은 예측·희망, 근거 수치 없음. 창작 도구 단락은 자사 접근 소개.
