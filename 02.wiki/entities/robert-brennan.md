# Robert Brennan

[[openhands|OpenHands]]의 CEO이자 공동창업자다. [[tech-bridge-openhands-sandboxing-coding-agents]]에서 이렇게 자기소개했다. *"my name is Robert Brennan. Uh, I'm the CEO at Open Hands."*(00:00~00:02) *"co-founded it a little over two years ago, really with the vision of bringing, uh, coding agents to the community"*(00:18~00:23). 설명란과 일치한다. 이 위키 첫 등장이다. 링크는 설명란에서 가져왔고 열어 보지 않았다.

## 위키에서 알려진 사실

- 2026년의 도약을 *"agents that run in the cloud"*로 보고, 그 이유로 *"there's not necessarily going to be a human there to babysit them"*(02:41~02:44)을 든다. → [[cloud-agent-delegation]]
- 로컬 실행의 trade-off를 승인 클릭으로 babysit하기와 *dangerously skip permissions* 사이의 양자택일로 정리한다(03:39~04:04). 처방은 최소 권한과 blast radius 축소다(04:41~05:27). → [[agent-sandboxing]] · [[least-privilege-connectors]]
- 실행 전략 넷(로컬 Docker · GitHub Actions · VM/Mac mini · Kubernetes)과 비교 축 다섯(local/remote · scale · isolation · persistence · triggers)을 제시한다. Kubernetes를 *"the most robust strategy"*(09:38~09:41)라고 부른다.
- *"sandboxing is not a panacea"*(12:15~12:18)라고 한다. 근거로 Anthropic Mythos 테스트 중 샌드박스 탈출(⚠️ 출처 미제시)과 구버전 Docker의 container escape를 든다.
- 자사 OpenHands Agent Canvas를 *"a quick plug"*로 소개한다(12:54~13:44).
