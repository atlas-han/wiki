# Molten Base

**스킬 관리자(skill manager).** [[tech-bridge-pstack-third-party-review]]의 **화자(이름 미상)가 만들었고**, 그 영상에서 **[[pstack|Pstack]]의 시연 대상**으로 쓰인다.

> **단 하루 오후에 저는 Molten Base라는 스킬 관리자를 만들었습니다 — 여러 에이전트에 흩어진 제 스킬을 전부 관리하려고요.** (00:28~00:35)

동기:

> **마음에 드는 스킬 관리자를 아직 못 찾았어요. 그러니 우리 것을 만들어 봅시다.** (01:52~01:56)

## 소스에서 확인되는 것

| 확인되는 것 | 근거 |
|---|---|
| **여러 에이전트에 걸친 스킬을 한곳에서 관리**하는 것이 목적 | 화자 진술 |
| **맥에서 먼저 돌고, 나중에 다른 시스템으로** | 에이전트가 정리한 요구사항(07:11~07:14) |
| **단일 프롬프트를 원샷**해 만들어졌다 | *"이 전체가 우리가 시작한 그 단 하나의 프롬프트를 원샷한 결과"*(06:49~06:53) |
| 제작 과정에서 **탐침 → 프레이밍 → 스캐폴딩 → 아레나(4 병렬) → 검증 → 감사** 를 거쳤다 | `show me your work` 출력 |
| 검증 단계에서 **에이전트의 허위 주장 세 건**이 잡혀 수정됐다 | 화자 진술 |
| 설명란 링크 `moltenbase.com` | 설명란 |

**공개 여부·라이선스·가격은 소스에 없다.**

## 왜 이 위키에 있는가

이 페이지의 값은 제품이 아니라 **증거의 위치**에 있다. [[pstack|Pstack]]의 실제 산출물 하나가 **제작자 본인이 아닌 사람의 손에서** 처음 만들어진 기록이고, [[tech-bridge-pstack-third-party-review]]의 **비용 비교(맨몸 30분 vs Pstack 1시간)** 가 측정된 대상이 바로 이것이다.

> ⚠️ **단일 사례다.** 이 하나의 프로젝트에서 나온 값을 일반 계수로 쓰지 않는다.
