# Thariq Shihipar

[[anthropic|Anthropic]] [[claude-code|Claude Code]] 팀 엔지니어. [[tech-bridge-claude-code-team-workflow]] 대담의 화자 3인 중 한 명이다.

> ⚠️ **이름은 채널 설명란에서만 확인된다.** 자막에는 이름이 거의 나오지 않아 **대담 안의 어느 발언이 이 사람의 것인지 소스로는 특정할 수 없다.** 아래 "팀이 말한 것"은 세 사람의 발언을 구분하지 않은 것이다.

## 팀이 말한 것 (화자 미특정)

- 업무의 **70~80%가 [[claude-tag|Claude Tag]]** 에서 일어난다. → [[goal-level-delegation]]
- 모델이 좋아지면 하네스 기능을 **지운다** — todo 리스트가 1년 만에 불필요해진 사례. → [[harness-pruning]]
- 기반 기술이 **2개월마다** 근본적으로 바뀌고 *"시간이 흐를수록 그 변화가 압축"* 된다.
- 코드 리뷰에서 태어난 **workflows** — fan-out → 3관점 적대적 검토 → map-reduce로 되접기. → [[dynamic-workflows]]
- *"**Claude는 자기만의 하네스를 만드는 데 정말 능숙**하죠."* → [[self-harness]]
- 사람에게 남는 것은 코드가 아니라 **결정의 역사**(*"이 API 구조가 왜 이런 식으로 되어 있는지"*).
