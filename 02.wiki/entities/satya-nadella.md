# Satya Nadella

[[microsoft|Microsoft]]의 CEO. 본 위키에는 Microsoft *"Copilot event"* 현장에서 진행자 Deirdre(성 Bosa는 설명란)의 새 쇼 *"DB Live"* 첫 게스트로 나온 대담([[tech-bridge-nadella-copilot-autopilot]], 업로드 2026-09-28)으로 첫 등장. **이 위키 첫 Microsoft 1인칭 화자**이자 [[openai|OpenAI]]의 파트너 쪽 CEO.

> ⚠️ **자막은 "Satya"뿐이다**(00:00). 성 **Nadella**와 **CEO** 직함은 제목·설명란에서 온다. 화자가 *"Microsoft was founded on"*(01:09~01:11), *"anything new from Microsoft"*(07:40~07:44)라 말해 소속은 자막이 확인한다.
>
> ⚠️ **당사자 진술.** 아래는 전부 자사 행사장·자사 제품 출시일의 발언이다.

## 위키에서 알려진 사실 (첫 소스 기준)

- **Copilot은 조합이다** — chat → co-work → code → **Autopilot**. *"I don't think of any one form factor as the be-all end-all"*(03:02~03:04), *"it's the composition"*(03:38). → [[microsoft-copilot]] · [[assistance-vs-automation]]
- **신뢰가 최대 이슈** — *"trust is going to be the maximum biggest issue"*(04:10~04:12), 그래서 [[agent-365|Agent 365]]가 *"probably the most important"*. → [[agent-governance-layers]]
- **한계비용이 있는 소프트웨어** — *"software for the first time has marginal cost"*(05:47~05:49), 좌석은 *"entitlements to usage"*(06:16~06:21). → [[software-marginal-cost]]
- **auto가 제품** — *"the last time I picked a model has been a long time"*, learned router, *"your agent picks the model"*(08:15~09:17). → [[model-mixing-economics]]
- **API 사용은 여전히 OpenAI가 지배**(11:25~11:29), OpenAI는 *"especially with Astra now"* 견인력(09:56~10:01). → [[openai-astra]]
- **OpenClaw가 영감** — *"open clock[=OpenClaw] came out and I think inspired … all of us"*(12:33~12:40). → [[openclaw]]
- **미·중 회담에는 사고 통보 체계** — 에이전트 자체가 **insider risk**(13:53~14:13). → [[ai-arms-limitation-lens]] · [[agentic-misbehavior]]
- **OpenAI–MS 공동 안전 위원회의 "embedded evaluators"**(15:48~16:05), 업계 단위로는 *"very diverse group"*, 식품 안전법 비유, **사후가 아니라 사전 규제**(16:34~17:30). → [[embedded-external-evaluators]]
- **데이터센터는 지역 사회의 허가** — 워싱턴주 Quincy(18:21~19:28). → [[data-center-local-backlash]]
- **추론 = 매출, 훈련 = R&D** — *"the laws of physics of the income statement"*(23:29~23:34). → [[inference-revenue-training-rnd]]
- **원칙** — *"anything that doesn't serve humans or is not in human control is not worth doing"*(24:25~24:30), 테스트 시간 늘리기와 단계적 출시(25:14~25:21).
