# Omarchy

[[dhh|DHH]]가 에이전트와 직결해 만드는 Linux 데스크톱/앱 스택. 사이트: [omarchy.org](https://omarchy.org). 본 위키에는 Lex Fridman 클립([[tech-bridge-dhh-agent-productivity]])의 실증 무대로 등장.

클립 기준: 약 3개월 작업. Quattro에 출시된 앱 세 개. **Omarchy Write** — iA Writer → Typora 대체, C++/Qt, 첫 버전 ~20분, 이틀 만에 Typora를 버리고 이후 에세이를 전부 여기서 씀. "각자 다른 5%를 에이전트로 다시 쓴다"의 구체 사례.

en-orig ASR은 Amachi / Amacha / Amacha Quattro / Amacha Write. 공식 표기 Omarchy로 통일.
