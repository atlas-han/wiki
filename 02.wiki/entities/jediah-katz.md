# Jediah Katz

[[cursor|Cursor]]에서 AI 에이전트 도구를 만든 개발자(설명란 *"커서에서 AI 에이전트 도구를 만들었던 제다이아 카츠"*, 원본 표기 *AI Engineer · Jediah Katz*). [[ai-engineer|AI Engineer]] 강연 *Smarter Models Killed the Harness. Here's What's Left*(`7Y4sbZgBdnc`)가 [[tech-bridge-jediah-katz-harness-whats-left]]의 원본이다.

## 위키에서 알려진 사실 (전부 그 강연의 발췌)

- **하네스가 줄어드는 메커니즘 = data flywheel**: 하네스가 더 어려운 코딩 작업을 손 닿게 하고 → 사용자가 늘고 → *"more coding data is shared with the labs"* → 모델이 네이티브로 배운다(02:12~02:31). → [[harness-pruning]]
- **되돌아온 가드레일**: Cursor에서는 prompting·guard rails를 지웠는데 [[grokbot|GrokBot]]에서는 *"putting back a lot of these things"* — 새 작업 때문(03:50~04:09).
- **남는 셋**: 자율 동료를 믿을 만하게 하는 인프라(작업이 *minutes → hours → days*, 노트북은 잠든다) · trust and security(*"all your API keys in a file"* 를 모델에 주지 말 것, 에이전트·사람별로 좁힌 권한) · efficiency. → [[always-on-agent-architecture]] · [[least-privilege-connectors]]
- 전망: 에이전트 작업의 90%가 노트북 밖(설명란은 *6개월 안에*, 발표자 전망).

## ⚠️ 유보

- 자막에 자기소개가 없다 — 이름·소속은 설명란과 해설뿐. 현재 소속(설명란 과거형)은 확인하지 않았다. 발췌에서 Cursor와 GrokBot을 모두 *"we"* 로 말한다 — 조직 관계는 [[spacex]]의 원칙대로 추정하지 않는다.
