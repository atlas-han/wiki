# Rafal Wilinski

[[runlayer|Runlayer]]의 founding engineer(직함은 발화됨). 전직은 *"leading Zapier agents and different AI teams"*(01:34~01:36). 이 위키의 유일한 소스는 [[tech-bridge-runlayer-self-improving-skills-mcp]] — 실행 트레이스에서 스킬을 증류하고 MCP로 전사에 배포하는 "self-improving organizational flywheel"을 다룬 17:37 발표다.

> ⚠️ **신원 근거.** en-orig엔 *"Hi, I'm Rafal. I'm a founding engineer at Rumlayer."*(01:24~01:31)까지만 있다. **성 Wilinski는 제목·설명란**(*"Runlayer의 Rafal Wilinski"*)과 링크 슬러그에서 나온다(링크는 열어 보지 않았다). `en` *"Ammar Fall"*·ko "아마르 폴"은 오인식이다. 자막과 설명란이 충돌하지는 않는다.

## 위키에서 알려진 것

- 스킬 = *"a playbook that essentially agent can read um when it thinks that the knowledge is relevant"*(02:08~02:15). 에이전트가 오래 일할수록 rabbit hole이 깊어지므로 초기 궤적을 잡는 스킬이 중요하다(03:41~04:14).
- 스킬의 세 문제: dev-centric, 아무도 playbook을 남기지 않음, 클라이언트 지원이 엇갈림. `npx skills`는 *"free prompt injections"*(06:04~06:09) → [[prompt-injection]]
- MCP = 스킬의 distribution layer, skills over MCP 워킹 그룹, resources 대신 tools로 구현 → [[mcp-skill-distribution]]
- Voyager의 skill library → *"exploration should be turned into reusable procedural knowledge"*(11:12~11:18), 성공·실패 트레이스 증류, 사람 게이트 없음 → [[run-trace-skill-distillation]]
- 36% → 100%(Sonnet 4.6, AWS Lambda 안의 Chromium fork) — ⚠️ 분모·실행 횟수가 발화되지 않음
- *"frontier intelligence is rented or borrowed"*(13:54~13:57), *"we all miss Fable"*(13:59) → moat = 증류 플라이휠 → [[company-knowledge-moat]]

⚠️ 벤더 발표 — 처방(원격 MCP 서버, MCP gateway)이 자사 구현과 겹친다. 측정 방법·고객 사례는 없다.
