# Zed

텍스트 에디터이고 **[[agent-client-protocol|ACP]]의 공동 제안자**. 본 위키 첫 등장은 [[tech-bridge-acp-universal-remote]].

## 위키에서 알려진 사실

- **Zed 쪽과 JetBrains 쪽이 팀을 이뤄** 클라이언트가 하네스를 제어하는 표준을 제안했다. 이것이 ACP의 출발이다.
- 동기는 에디터 제작자의 것이다 — *"에디터에 **고품질 클라이언트 구현을 하나만** 작성해서(Zed든 IntelliJ든) **그 하나로 어떤 하네스든 제어**하고, 과제를 보내고 결과를 받고 어떤 파일이 편집되는지 본다."*
- [[goose|Goose]] 팀의 평가 — 프로토콜이 **비교적 중립적이고 에디터 전용 기능이 별로 없어서** 에디터를 넘어 퍼질 수 있다.
- 소스의 첫 데모에서 **ACP 클라이언트**로 쓰인다(Zed에 질의를 입력 → Goose가 텍스트와 도구 호출 정보를 돌려보냄).
