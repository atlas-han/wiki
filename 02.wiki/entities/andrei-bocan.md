# Andrei Bocan

[[atlassian|Atlassian]]에서 **AutoDev**를 맡고 있다. [[andy-wong|Andy Wong]]이 *"Andre, uh you've been working on autodev pretty heavily"*(38:56~38:59)라며 넘겼다. 이름은 Andy의 소개(en-orig *"Andre Bohan"* 00:20)에 나오고, 철자 Bocan은 제목·설명란에서 왔다. [[tech-bridge-atlassian-build-your-own-sdlc]]가 이 위키의 첫 등장이다.

## 위키에서 알려진 사실

- AutoDev를 *"our forign[=foray] to like the AISDLC orchestration space"*(39:28~39:31)로 소개했다. 백로그에서 에이전트가 자율로 처리할 수 있다고 확신하는 항목을 골라 PR을 올린다(39:48~40:02).
- standards를 *"pretty similar to linting (…) but they're a lot more uh loose"*(40:54~41:00)라고 말했다.
- 리뷰 부담을 제한한다 — *"nobody wants to spend time reviewing uh 50 PRs a day"*, 1인당 주 3~5 PR 설정(41:46~42:01), WIP 한도(43:50~43:58), 비용 한도는 *"just table stakes"*(44:18~44:28). → [[review-wip-limit]]
- ⭐ *"the reviewing step is where things go to die"*(45:32~45:35). Slack으로 적절한 때 리뷰어를 호출한다(45:43~46:00).
- 저명세 백로그 항목은 사람에게 명세를 요청한다(44:41~45:25).
- 모델 라우팅 답: *"We currently don't have anything out uh that would do be doing like doing smart routing"*(31:49~31:53). 모델 선택은 하네스 최상위 + 스킬별이다(32:52~33:05).
- (⚠️ 추정 — 이름으로 지목되지 않은 Wi-Fi 장애 중 Q&A의 응답자) context engine을 *"agentic search on top of all of all of that context"*(17:10~17:14)로, 모노레포를 *"the debt of having a monor repo"*(18:37~18:40)로 설명했다. 충돌 정보는 *"you need a human to tell like yes, this is actually true"*(20:23~20:25)라고 답했다.

## ⚠️ 유보

- 직함은 발화되지 않는다. organizational steering(Rails 버전 이전, *"10,000 services"* 42:25~42:30)은 **비전·가정 예시**다.
