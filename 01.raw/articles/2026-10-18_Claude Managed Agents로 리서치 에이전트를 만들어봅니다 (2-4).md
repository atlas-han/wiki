## 원 설명란

원라인 콘솔 에이전트에서 스킬·하위 에이전트·메모리를 갖춘 리서치 데스크까지, Claude Managed Agents로 직접 만들어 봅니다.

Anthropic의 Priyanka Phatak과 Gabe Cemaj가 세션 이벤트 스트림에 연결한 채팅 UI를 만들고, SEC EDGAR 스킬과 하위 에이전트, 맞춤 도구를 더합니다. 이어서 평가 기준과 채점기를 둔 Outcome 작업으로 Nvidia를 분석하고, 에이전트가 결과를 점검하며 다시 시도하는 과정을 보여줍니다.

주요 내용
• 이벤트 스트림을 활용한 리서치 데스크 채팅 UI
• SEC EDGAR 스킬, 하위 에이전트, 맞춤 도구 구성
• 평가 기준과 채점기로 결과를 확인하는 Outcome 작업
• Vault를 통한 비밀 정보 주입과 공유 메모리
• Agent SDK, 가드레일, 세션 분기, MCP 터널 Q&A
